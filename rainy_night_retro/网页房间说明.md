# 雨落之后 · 网页房间（书桌前 → 电脑 → 纸上常州）

## 文件
- `room.html`：网页房间入口（three.js）。
- `web/room.glb`：从 `After_Hours_Rainy_Room.blend` 导出的模型（约 2.3 MB，Draco 压缩）。
- `export_web.py`：导出脚本。改了 Blender 场景后重新运行即可，不会修改 `.blend`。

```powershell
& 'D:\blender\blender.exe' --background '.\After_Hours_Rainy_Room.blend' --python '.\export_web.py'
```

## 打开方式
模型需要通过本地服务器加载，不能直接双击 html。在 `cz` 文件夹（游戏文件所在的上一级）启动服务器：

```powershell
python -m http.server 5178
```

浏览器打开 `http://localhost:5178/rainy_night_retro/room.html`。

## 操作
- 拖动画面环顾；W A S D / 方向键走动；「锁定视角」按钮进入鼠标锁定模式。手机上左下角有方向键。
- 走到书桌前（3.2 米以内）点击电脑屏幕：镜头推进屏幕 → 复古电脑桌面 → 选择篇章 → 游戏全屏打开。
- 游戏里按 Esc，或点顶部「退出到电脑桌面」，回到桌面；桌面上点「关机 · 离开电脑」回到房间。
- 点击台灯灯罩可以开关台灯；右上角可以关掉雨声（浏览器实时合成，没有音频文件）。

## 视角与走动的限制（room.html 顶部可调）
- `LOOK`：`drag` 拖动灵敏度、`lock` 锁定视角时的灵敏度、`damp` 转向缓动（越大越跟手）、`pitchMin / pitchMax` 低头 / 抬头角度、`speed` 走路速度（米/秒）。
- `EDGE_R / EDGE_L`：右侧窗帘墙垛和左墙后端两个点。转向时会按当前站位和屏幕宽度自动计算，保证画面边缘不越过这两点，也就只能看到前方和左侧（右边和后面没有建模）。
- `BOUNDS`：可走动的范围；`BLOCKS`：床、椅子等不能穿过的家具。
- 调试：网址末尾加 `#debug`，可在控制台用 `__view(x, z, 朝向, 俯仰)` 直接摆机位。

## 和游戏的衔接
- 游戏文件路径在 `room.html` 顶部的 `GAME_ROOT`（默认 `../`），篇章列表在 `CHAPTERS`。
- 屏幕画面和电脑桌面读取同一份存档 `cz-scroll-v1`，会显示各篇是否已完成。

## 与 Blender 渲染的差异
- Blender 里的面光源导不进网页，网页里用聚光灯、点光源和矩形光重新布光，效果接近但不完全一致。
- 程序化材质（噪波纹理、凹凸）导出时改成了平均色，木纹等细节会变平。如果想更接近渲染效果，可以在 Blender 里把光照烘焙成贴图后再导出。
- three.js 从 jsDelivr 加载，比赛现场如果没有网络，需要把 three.js 下载到本地并修改页面里的 importmap。
