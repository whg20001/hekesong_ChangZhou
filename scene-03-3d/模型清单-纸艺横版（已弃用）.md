# 巧排任务 · 3D 版 模型清单与风格规范

> 现代篇 · 华罗庚 × 统筹与优选。本文档交给建模的人 / agent 使用；模型做完回传后，由我统一检验、组装进 three.js 场景。

---

## 0. 场景怎么玩（建模前先看）

- **视角**：2.5D 横版。玩家沿一条纸艺街道从左走到右，镜头在侧前方略俯视（约 15°），能看到物体的正面和一点侧面。**背面不会被看到，可以不做。**
- **三个区段 = 三段剧情**，每段走到节点触发小游戏，小游戏时镜头推近到一张“特写布景”：

| 区段 | X 范围（米） | 剧情 | 特写布景 |
|---|---|---|---|
| A 金坛老街 | 0 – 20 | 柜台上的演算（速算） | 杂货铺柜台 |
| B 茶室 | 20 – 40 | 统筹方法（泡茶排序） | 泡茶桌 + 炉子 |
| C 车间 | 40 – 60 | 优选法（0.618 寻炉温） | 熔炉 + 黑板 |

- **路上的玩法物件**：可收集的数学符号、需要跳上去的纸条平台、滚过来要跳过的纸圈。
- 小游戏的界面（甘特图、刻度尺、选项按钮）由我用网页做，**不需要建模**。

## 1. 统一风格：彩色纸艺立体书

一句话：**像用彩色卡纸剪出来、立在桌上的立体书 / 纸模型**。

### 必须遵守
1. **全部是有厚度的纸片 / 纸板块**：薄板挤出。普通纸片厚度 2–3 cm，墙体等大块 5–8 cm。不要圆滑的有机曲面。
2. **扁平纯色，不画贴图**：每个面只用下面调色板里的一种颜色。纸纹、颗粒由我在网页里统一加。
3. **剪纸边缘**：主要物体背后加一层略大 1–2 cm 的白色衬纸（色号 `WHITE`），模拟剪纸的白边。
4. **轻微不规整**：零件可以有 1–3° 的随手歪斜，不要完全对齐，更像手工。
5. **硬边**：不用平滑着色，只允许极小倒角（≤ 0.5 cm）。
6. **不建文字**：招牌、黑板、账本上的字一律不建模。留一块空白平面，命名为 `SIGN_xxx`，文字由我在网页里贴上。

### 调色板（材质名 = 色名，**只能用这 12 个材质**）

| 材质名 | 色值 | 主要用途 |
|---|---|---|
| `P_CREAM` | `#F4ECDC` | 纸底、墙面、地面浅色 |
| `P_WHITE` | `#FFFAF0` | 剪纸白边、窗格、杯子 |
| `P_NAVY` | `#22314F` | 路面、深色结构、阴影块 |
| `P_TEAL` | `#2F8F83` | 主色：车间、植物、茶室点缀 |
| `P_MUST` | `#E0A526` | 主色：杂货铺、齿轮、高光 |
| `P_CORAL` | `#E2674A` | 主色：屋顶、警示、纸圈 |
| `P_PINK` | `#F0B3A2` | 茶室墙面、柔和点缀 |
| `P_SKY` | `#9CC7D8` | 远山、玻璃、远景楼 |
| `P_INK` | `#1D1D1B` | 眼镜、头发、鞋、细线 |
| `P_SKIN` | `#F1D2B5` | 人物皮肤 |
| `P_SUIT` | `#5B6B82` | 华罗庚的中山装 |
| `P_WOOD` | `#8A5A3A` | 柜台、桌椅、手杖 |

材质设置：Principled BSDF，粗糙度 0.85，金属度 0，**不要连接任何节点**（程序纹理导不进网页，会变成白色）。

## 2. 技术规范（回传前请自查）

| 项目 | 要求 |
|---|---|
| 软件 | Blender（4.x / 5.x 均可） |
| 单位 | 1 单位 = 1 米，人物身高 1.75 m |
| 朝向 | **正面朝 Blender 的 −Y**（即镜头方向），Z 向上 |
| 原点 | 道具放在**底面中心**；会转动的零件放在**转轴处**（见各条备注） |
| 变换 | 导出前 Apply 全部缩放和旋转（Ctrl+A → All Transforms） |
| 修改器 | 导出时应用（导出面板勾选 Apply Modifiers） |
| 面数 | 每个道具标注了上限；全场景合计 ≤ 15 万三角面 |
| 法线 | 统一朝外，不要有翻面（视图里开启 Face Orientation 检查，应全部为蓝色） |
| 格式 | **glTF 2.0 二进制 `.glb`**，每个编号一个文件，文件名用编号，如 `C01_hua.glb` |
| 不要包含 | 灯光、相机、动画、未用到的材质、隐藏物体 |

### 命名前缀（我靠名字找物体，请严格遵守）
- `ANIM_`：需要我在网页里做动画的零件（如水壶盖、齿轮、指针）
- `SIGN_`：留给我贴文字的空白面
- `PLAT_`：平台的可站立顶面
- `COL_`：不可见的碰撞盒（简单长方体即可，材质随意，我会隐藏）
- 其余物体随意命名，但不要重名

## 5. 回传与检验

- 每个模型一个 `.glb`，放进 `scene-03-3d/models/`，文件名用编号开头（如 `B04_kettle.glb`）。
- 回传时附一张从正前方（Blender 视图 −Y 方向）截的预览图，命名同编号。
- 我会自动检查：尺寸是否符合本表（误差 ±15%）、原点位置、朝向、`ANIM_` / `SIGN_` 零件是否齐全、材质是否只用调色板里的 12 种、面数是否超限、有无翻转法线。不合格的我会列出具体问题退回。
