# 巧排任务 · 第一人称 3D 展馆（网页）

## 文件
- `hua-museum.html`：游戏页（three.js）。模型直接读取 `../material/` 里 Codex 交付的 `S0_shell` ~ `S6_common.glb`，不需要另外导出。
- `museum-dress.js`：网页端的细化层，不改模型文件。包括：
  - 材质细节：木纹、墙面、砖墙的程序化着色，以及天窗、门窗玻璃上的雨痕；
  - 布景道具：红地毯、隔离栏、灯笼、米袋、老照片、茶席、书架、挂轴、警示线、管道、木箱、油桶、工业吊灯、海报、工具挂板、黄金分割小画、长凳、门外的雨夜街景；
  - 氛围：光柱、浮尘、门外的雨、闪电。

  想加减道具，就改这里的 `buildProps()`。
- `model_check.html`：模型检视页，只看模型、不含玩法，用来复查 Codex 的新导出。
- `模型清单.md` / `模型检验反馈.md`：建模规范与两轮检验记录。

## 打开方式
在 `cz` 文件夹启动本地服务器（不能直接双击 html）：

```powershell
python -m http.server 5178
```

- 单独玩：`http://localhost:5178/scene-03-3d/hua-museum.html`
- 从卧室进入：`http://localhost:5178/rainy_night_retro/room.html` → 点电脑屏幕 → 选「巧排任务」。卧室的篇章列表已改为指向本页。

## 玩法
- 拖动画面环顾，W A S D 走动，Shift 快走；「锁定视角」后用准星点击。
- 指向展品时会高亮并出现提示，点击互动：铜像、时间轴、手稿展柜、说明牌、结语墙都有讲解。
- 场馆里漂着 8 张数学符号卡，走近就能收集，每张 +3 灵感。
- 三处展区（顺序不限）：
  1. **柜台速算**（展厅一）：三位纸板客人报出买的东西。镜头先看客人，再俯看算盘。拨右边三档朱红色算盘珠作答，上珠当 5、下珠当 1；也可以直接按数字键。按 Enter 找钱，每位限时 40 秒。
  2. **统筹泡茶**（展厅二）：依次点水壶（洗水壶）、炉子（烧开水）、茶壶（洗茶壶，再点一次是泡茶）、茶杯、茶叶罐。左上角时间表和墙上的甘特图会同步画出来，最优是 16 分钟，最多可以重排 3 次。
  3. **优选炉温**（展厅三）：拖动旋钮，或用滚轮、← → 键设定温度，再按红色按钮做试验。炉门打开、压力表指针摆动，试样架上的方块按合格率变色，黑板画出保留的区间。把范围缩到 50℃ 以内即完成，0.618 法大约需要 8 次。
- 每完成一处，尾厅的黄金螺旋就亮起几块。三处都完成后，出口打开。点出口门把门推开，走进「纸上常州」的光里，就会出现结算面板并写入存档。结算面板可以跳到终章。
- 展台里按 Esc 或点「离开」回到走动状态，不计分；点「跳过此展区」记为“未评”。

## 与其他篇章的衔接
- **存档**：写入 `cz-scroll-v1` 的 `chapters.hua`，内容为 `{grades, res, resName: '灵感', cards}`，格式与平面版相同，终章可以直接读取。
  - `res` = 符号卡 ×3 + 各展区奖励（甲 6 / 乙 4 / 丙 2）。
  - `cards` 是 6 张图鉴：金坛、小店自学、走进清华、统筹法、优选法、数学符号。
- **跳转地址**：本页顶部 `NEXT_URL` 设为 `../scene-04-finale.html`。终章人物卡里的「华罗庚 · 再玩一次」也已指向本页。
- **还没改的地方**：第二篇 `scene-02-liu.html` 的 `NEXT_URL` 仍指向平面版 `scene-03-hua.html`。如果要串成线性流程，组合时把它改成 `scene-03-3d/hua-museum.html`。

## 调试入口（加在网址末尾）
- `#ep1` / `#ep2` / `#ep3`：直接站到某个展区前。
- `#exit`：三处展区记为完成，站在尾厅，用来测试出口和结算。
- 控制台的 `__museum.view(x, y, 朝向角度, 俯仰角度)` 用平面图坐标摆机位；`__museum.game` 是当前进度。

## 可调参数（`hua-museum.html` 顶部）
- `LOOK`：拖动灵敏度、锁定灵敏度、转向缓动、俯仰范围、走路 / 快走速度。
- `EYE` / `RADIUS` / `REACH`：视线高度、碰撞半径、可互动距离。
- 各展区镜头位置在 `shop.look()`、`tea.eye/at`、`opt.eye/at`；符号卡位置在 `SYMS`。
- 灯光在 `setupLights()`：射灯隔一盏放一个真光源，阴影只开在雕像、柜台、茶桌、熔炉四处。性能不够时，可以关掉 `renderer.shadowMap` 或减少射灯数量。

## 画面
- **灯光**：底光压暗，每件主要展品各分一盏射灯；四盏开阴影，分别照铜像、柜台、熔炉、黄金螺旋。两处天窗漏下冷色月光，每隔 25–50 秒打一次闪电，随后有雷声。
- **后期**：环境光遮蔽（家具落地处和墙角的接触阴影）→ 指向展品时的描边 → 泛光 → 暗部偏冷、亮部偏暖的调色和暗角。
- **画质自适应**：进馆后约 4 秒，如果平均帧时间超过 26 毫秒，先关环境光遮蔽，仍然慢就再关阴影。控制台会打印 `[画质]` 提示。
- **声音**：雨声、脚步声、雷声，以及各种交互音效，全部用 WebAudio 实时合成，没有音频文件。

## 已知限制
- three.js 和中文字体从 CDN（jsDelivr、Google Fonts）加载，比赛现场没有网络时需要改成本地文件。
- 门、炉门、壶盖、算盘珠等动画都在网页里程序生成，没有用模型自带的动画。
