## 0. 选定场景：闭馆后的华罗庚数学展馆

**一句话**：雨夜，玩家从卧室的电脑屏幕“走进”一座闭馆后的展馆。馆里只亮着暖色射灯，三个情景复原展区分别对应三段剧情，按参观路线一路体验下去。

- 场景是**以金坛华罗庚纪念馆为灵感的虚构展馆**，不是真实建筑的复原，馆内说明会注明这一点。
- **第一人称**：玩家是参观者，没有主角模型、手臂和行走动画。WASD 走动，鼠标转向，准星对准展品时按 E 键或点击互动。
- 三个小游戏的玩法逻辑沿用 2D 版，但改成**直接操作场景里的 3D 物件**（点选茶具、拨动炉温旋钮）。
- 氛围、建模风格与卧室场景 `rainy_night_retro/After_Hours_Rainy_Room.blend` 保持一致。

### 参观路线

| 顺序 | 区域 | 剧情 / 作用 | 互动 |
|---|---|---|---|
| 1 | 序厅 | 华罗庚雕像、生平时间轴墙、雨夜天窗 | 看展、收集数学符号卡片 |
| 2 | 展厅一 · 小店里的演算 | 复原金坛杂货铺柜台（1920 年代） | 站到柜台后，给立牌“客人”速算找零 |
| 3 | 展厅二 · 统筹方法 | 复原茶室一角（《统筹方法》的泡茶例子） | 按顺序点选茶具，墙上的甘特图展板同步画出时间线 |
| 4 | 展厅三 · 优选法 | 复原工厂车间一角（熔炉 + 黑板） | 拨动炉温旋钮做试验，黑板显示 0.618 区间收缩 |
| 5 | 尾厅 | 黄金螺旋装置、出口门 | 走出出口门，进入终章 · 纸上常州 |

## 1. 风格：温暖复古的低多边形微缩场景（与卧室一致）

请把卧室的两张渲染图作为风格参考发给建模 agent：
`rainy_night_retro/雨落之后_窗前书桌.png`、`rainy_night_retro/雨落之后_房间全景.png`。

### 造型
- 低多边形，比例略夸张，**所有边都有圆润倒角**（2–10 mm），带一点玩具、微缩模型的手感，和卧室里的书桌、CRT 电脑是同一种手感。
- 允许平滑着色（Shade Auto Smooth），表面干净，不追求写实磨损。

### 氛围
- 夜晚、闭馆、下雨。主光是**暖色射灯**照亮的展品，背景是**偏冷的深蓝夜色**（天窗、窗外、阴影）。
- 三个复原展区各有一个代表性的光源（由我在网页里布光，建模时只需把发光面单独做出来）：
  - 展厅一：柜台上的煤油灯，暖黄。
  - 展厅二：炉火加挂钟下的小吊灯，橙色。
  - 展厅三：熔炉炉口，橙红；车间高窗，冷蓝。

### 主色参考（不是硬性限制，但请以这些颜色为主）

| 用途 | 色值 |
|---|---|
| 胡桃木 / 深木 | `#6B4129` |
| 暖木 / 柜台 | `#9A6A43` |

主题叫“纸上常州”，展馆里可以多放些纸质的东西：宣传画、窗花剪纸、黑板粉笔字、纸质说明牌、可收集的数学符号纸卡。字一律由我贴上（见下面的 `SIGN_` 规则）。

## 2. 技术规范（回传前请自查）

| 项目 | 要求 |
|---|---|
| 软件 | Blender（4.x / 5.x 均可） |
| 单位 | 1 单位 = 1 米；玩家视线高 1.6 m，按真实尺寸建 |
| 坐标 | **按第 0 节平面图的世界坐标直接摆放**；Z 向上，地面 Z = 0 |
| 原点 | 单个道具：底面中心；会转动的零件：转轴处 |
| 变换 | 导出前 Apply 全部缩放和旋转 |
| 材质 | Principled BSDF；**不要用程序化纹理节点**（噪波、色带等导进网页会变成白色，卧室就出现过）。需要木纹、砖纹时用图片贴图，单张 ≤ 1024×1024，全场景贴图 ≤ 12 张 |
| 透明玻璃 | 用 Alpha 设成半透明，不要用 Transmission |
| 灯光 | **不要导出灯光**（面光源导不进网页，由我重新布光）；发光的面用自发光材质，命名 `EMIT_` |
| 面数 | 每项见清单；全场景合计 ≤ 25 万三角面 |
| 法线 | 统一朝外（Face Orientation 全部为蓝色） |
| 格式 | **glTF 2.0 二进制 `.glb`**，开启 Draco 压缩 |
| 不要包含 | 灯光、相机、动画、隐藏物体、辅助物体（卧室里就混进过一个 2 米大的 `Lamp pivot` 球） |

### 命名前缀（我靠名字找物体，请严格遵守）
- `INT_`：可以互动的物体（准星对准会高亮），如 `INT_kettle`
- `ANIM_`：需要我做动画的零件，如 `ANIM_minHand`
- `SIGN_`：留给我贴文字或画面的空白面，如 `SIGN_timeline_01`（**不要建任何文字**）
- `EMIT_`：自发光的面，如 `EMIT_lampGlass`
- `COL_`：不可见的碰撞盒（大件家具和墙体，用简单长方体即可，我会隐藏）
- 其余物体随意命名，不要重名
